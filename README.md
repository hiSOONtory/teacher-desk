# 교사 대시보드

바탕화면에 띄워 두는 선생님용 대시보드예요. 무료 프로그램 **Lively Wallpaper**로 바탕화면 배경 자리에 띄워요.

- **지금 몇 교시인지**, 남은 시간, 오늘 시간표 (교시를 눌러 메모·수업 교환·보강)
- **진도**: 반마다 나간 차시와 남은 수업 시간, 여유·부족
- **출결**: 번호만 누르면 기록. 지각·조퇴는 몇 교시부터, 결과는 빠진 교시까지. 하루·누적 보기
- **마감 업무**: 할 일과 마감일
- **학사일정·D-day·급식**: 학교만 고르면 나이스에서 매일 자동으로 가져와요
- **칸 배치**: 칸 순서를 바꾸거나 안 쓰는 칸을 숨길 수 있어요

기록은 **내 컴퓨터에만** 저장돼요. 어디로도 보내지 않아요.

또는 이 페이지 위쪽 초록색 **Code** 버튼 → **Download ZIP**을 눌러 받은 뒤 압축을 풀어요.

## 설치 (10분)

1. **Microsoft Store**에서 `Lively Wallpaper`를 찾아 받아요 (무료).
2. Lively를 열고 `teacher-desk-lively.zip`을 **압축 풀지 말고 Lively 창 안으로 끌어다 놓아요.** 목록에 생긴 “교사 대시보드”를 누르면 바탕화면이 돼요. (안 되면 압축을 풀어 안에 있는 `teacher-desk.html`을 끌어다 놓아도 돼요)
3. **꼭 하세요** — Lively 설정(⚙)에서 **디스크 캐시**를 켜고 Lively를 한 번 껐다 켜요. 안 켜면 껐다 켤 때마다 넣은 내용이 사라져요.
4. 바탕화면에 뜬 **시작하기**를 눌러 학교를 고르고 시간표 파일(한글·PDF·엑셀)을 넣어요.
5. 원하면 대시보드 ⚙ → 화면 · 알림에서 **왼쪽 여백**(바탕화면 아이콘 자리)과 **칸 배치**를 바꿔요.

모니터가 두 대면 Lively 설정의 **배경 화면 배치 방식**을 **복제**로 두면 두 화면에 다 떠요.

**중요:** 학교·시간표는 **Lively 바탕화면에 뜬 대시보드에서** 넣어야 해요. 파일을 더블클릭해서 크롬·엣지로 연 화면에서 넣으면 그 브라우저에만 저장돼서, 바탕화면에서는 빈 화면으로 보여요.

## 쓰면서 알아 두세요

- 마우스 **휠은 안 먹어요** (Lively가 휠을 넘겨주지 않아요). 큰 창에서 목록을 내릴 땐 잡고 끌어요.
- **글자 칸을 누르면** 작은 입력 창이 떠요. 거기에 쓰고 확인을 누르면 들어가요.
- 칸에는 꼭 필요한 것만 보여요. **제목이나 칸을 누르면** 큰 창으로 자세히 나와요.
- 가끔 ⚙ → 백업 · 초기화 → **백업 파일 저장**을 해 두세요. 무슨 일이 있어도 **백업 파일 불러오기** 한 번이면 돌아와요.
- 컴퓨터 메모리가 빠듯하면 대시보드가 멈출 수 있어요(시계가 멈춰 있음). 이럴 땐 작업 표시줄 오른쪽 Lively 아이콘 → 종료 → 다시 실행하면 돼요.

## 마감요정과 같이 쓰기 (선택)

브리티 쪽지의 마감을 챙겨 주는 [마감요정](https://github.com/hiSOONtory/deadline-fairy-release)과 이어 쓰면, 쪽지 마감이 대시보드 **마감 업무** 칸에 저절로 떠요. 그림으로 된 안내는 `마감요정_연동_설명서.html`에 있어요.

1. **마감요정을 켜요.** 작업 표시줄 오른쪽에 요정 아이콘이 보이면 켜진 거예요. (🚀 버튼을 켜 두면 컴퓨터를 켤 때 같이 켜져요)
2. **브리티에서 쪽지를 열어 읽어요.** 열어 본 쪽지만 마감요정이 알아요. 마감요정은 읽기만 하고 대신 클릭하지 않아요.
3. **대시보드 마감 업무 칸을 봐요.** 🧚 표시가 붙은 일이 약 10초 안에 나타나요. 따로 설정할 건 없어요.
4. 대시보드에서 **○(완료)·×(삭제)** 를 누르면 마감요정에도 똑같이 반영돼요.

**꼭 알아 두세요**

- 마감요정과 대시보드는 **같은 컴퓨터**에 있어야 해요. 연결은 컴퓨터 안에서만 이뤄지고, 쪽지 내용은 밖으로 나가지 않아요.
- 연동은 **연동판(`teacher-desk-magam-lively.zip`, 안에 `teacher-desk-magam.html`)** 과 **마감요정 1.7 이상**이 있어야 해요. `teacher-desk.html`은 마감요정 없이 쓰는 기본판이라 연동 기능이 없어요. 둘 중 하나만 Lively에 올리세요. (연동판을 올려도 마감요정이 없으면 기본판처럼 쓸 수 있어요)
- 안 보이면: 마감요정이 켜져 있는지, 쪽지를 열어 읽었는지, 쪽지에 마감 날짜가 있는지 순서대로 확인하세요. 마감이 없는 안내·공람 쪽지는 올리지 않아요.
- 덤으로, 대시보드가 2분 넘게 멈춰 있으면 마감요정이 Lively를 다시 켜 주고, Lively가 못 넘겨주는 마우스 휠도 대신 전해 줘요.

## 자꾸 처음 화면으로 돌아가요

대부분 **디스크 캐시가 꺼져 있어서**예요. `대시보드_점검.bat`을 더블클릭하면 원인을 찾아 주고, 디스크 캐시가 꺼져 있으면 물어본 뒤 켜 줘요. 결과는 바탕화면 `대시보드_점검결과.txt`에 저장돼요.

직접 고치려면 Lively를 **완전히 종료**한 뒤, 아래 폴더의 `Settings.json`을 메모장으로 열어 `"CefDiskCache": false`를 `true`로 바꾸고 저장해요.

```
%LOCALAPPDATA%\Packages\12030rocksdanister.LivelyWallpaper_97hta09mmv6hy\LocalCache\Local\Lively Wallpaper
```
