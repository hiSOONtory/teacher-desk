교사 대시보드
바탕화면에 붙이기

교실 벽 시간표를 내 컴퓨터 바탕화면에 붙인다고 생각하면 돼요.
따라 하면 10분이면 끝나요.

준비물은 딱 두 개

Lively는 바탕화면에 그림을 걸어 주는 액자,
대시보드 묶음은 그 액자에 넣을 그림이에요.

⬇
1

액자(Lively)부터 깔아요

시작 메뉴에서 Microsoft Store를 열고
Lively Wallpaper를 찾아 받기를 눌러요.

무료예요. 회원 가입도 필요 없어요.
⬇
2

그림(대시보드 묶음)을 받아요

아래 버튼을 누르면 다운로드 폴더에 받아져요.
받은 그대로 두면 돼요.

⬇ 대시보드 묶음 받기 마감요정을 같이 쓰는 분은 연동판 묶음을 받으세요. 둘 중 하나만 있으면 돼요.
⬇
3

액자에 그림을 넣어요

Lively를 열고, 받은 파일을 마우스로 꾹 잡아서 Lively 창 안에 놓아요.

목록에 “교사 대시보드”가 생기면, 그걸 한 번 눌러요.
바탕화면이 대시보드로 바뀌어요.

끌어다 놓기가 안 되면: 파일을 오른쪽 클릭 → 압축 풀기 → 안에 있는 teacher-desk.html을 끌어다 놓아도 돼요.
⬇
4이건 꼭 하세요

기억 스위치를 켜요

Lively 창의 ⚙ 설정에서 디스크 캐시를 켜요.
그다음 Lively를 한 번 껐다 켜요.

왜 켜요? 이 스위치가 꺼져 있으면 컴퓨터를 끌 때마다 넣어 둔 시간표·출결을 다 잊어버려요. 켜 두면 계속 기억해요.
Lively 끄는 법: 화면 맨 아래 오른쪽(시계 옆)의 Lively 아이콘을 오른쪽 클릭 → 종료. 그리고 다시 실행해요.
⬇
5

우리 학교와 시간표를 알려 줘요

바탕화면에 뜬 시작하기를 누르고
화면이 묻는 대로 따라가요.

학교를 고르면 학사일정과 급식은 매일 저절로 와요. 시간표는 갖고 있는 한글·PDF·엑셀 파일을 그대로 넣으면 돼요.
주의! 꼭 바탕화면에 뜬 대시보드에서 넣어요. 파일을 더블클릭해 인터넷 창(크롬·엣지)으로 열어서 넣으면 바탕화면에는 안 보여요.
⬇

🎉 끝났어요!

이제 바탕화면에서 지금 몇 교시인지, 진도, 출결, 할 일을 볼 수 있어요.

거기에 쓰고 확인.
🖐️마우스 휠은 안 돼요

💾가끔 백업해요
⚙ → 백업 · 초기화 → 파일로 내보내기.

막혔을 때

바탕화면 아이콘이 대시보드에 가려요

대시보드 오른쪽 위 ⚙ → 화면 · 알림에서 왼쪽 여백을 늘려요. 같은 곳의 칸 배치에서 칸 순서를 바꾸거나 안 쓰는 칸을 숨길 수도 있어요.

컴퓨터를 켤 때마다 처음 화면으로 돌아가요

4번의 기억 스위치(디스크 캐시)가 꺼져 있어서예요. 다시 켜고 Lively를 껐다 켜요. 그래도 안 되면 점검 도구와 td-check.ps1을 같은 폴더에 받아 점검 도구를 더블클릭해요. 원인을 찾아 줘요.

시계가 멈춰 있어요

컴퓨터가 바쁘면 가끔 멈춰요. Lively를 껐다 켜면 돌아와요(시계 옆 Lively 아이콘 오른쪽 클릭 → 종료 → 다시 실행).

모니터가 두 개예요

Lively 설정의 배경 화면 배치 방식에서 “복제”를 고르면 두 화면에 다 떠요.

넣은 내용은 내 컴퓨터에만 저장돼요. 어디로도 보내지 않아요.
더 자세한 방법은 대시보드 ⚙ → 사용 방법에 있어요.
