교사 대시보드
바탕화면에 띄우기

무료 프로그램 하나 깔고, 파일 하나 넣으면 끝이에요.

10분이면 돼요
1단계

Lively 깔기

Microsoft Store에서 Lively Wallpaper를 찾아 받기.

무료예요. 시작 메뉴에서 “Microsoft Store”를 열면 돼요.
2단계

파일을 한곳에 두기

teacher-desk.html을 지우지 않을 폴더에 넣어요.

예: 문서 폴더 안에 “교사대시보드” 폴더를 만들어서.
3단계

Lively에 끌어다 놓기

Lively를 열고 파일을 창 안으로 끌어다 놓아요.

안 되면 Lively의 ＋ 배경화면 추가 → 파일 고르기. 목록에 생긴 대시보드를 누르면 바탕화면이 돼요.
4단계 · 꼭 하세요

Lively 설정 두 개 켜기

① 디스크 캐시 켜기
안 켜면 컴퓨터를 껐다 켤 때 넣은 내용이 사라져요.

② 배경화면 입력에서 키보드 켜기
학교 이름처럼 글자를 칠 때 필요해요.

둘 다 Lively 창의 ⚙ 설정에 있어요. 바꾼 뒤엔 Lively를 한 번 껐다 켜요(작업 표시줄 오른쪽 Lively 아이콘 오른쪽 클릭 → 종료 → 다시 실행).
5단계

학교 고르고 시간표 넣기

바탕화면에 뜬 시작하기를 누르고 따라가요.

학교를 고르면 학사일정·급식은 나이스에서 매일 자동으로 와요. 시간표는 한글·PDF·엑셀 파일 그대로 넣으면 돼요.
6단계 · 원하면

내 화면에 맞추기

대시보드 오른쪽 위 ⚙ → 화면 · 알림에서 바꿔요.

· 아이콘이 가리면 왼쪽 여백을 늘려요.
· 칸 배치에서 칸 순서를 바꾸거나 안 쓰는 칸을 숨겨요.

모니터가 두 개면 Lively 설정의 배경 화면 배치 방식에서 “복제”를 고르면 두 화면에 다 떠요.

쓰면서 알아 두세요

  • 마우스 휠은 안 먹어요. 큰 창에서 목록을 내릴 땐 잡고 끌어요(휴대폰처럼).
  • 글자를 다 쳤으면 키보드 입력은 다시 꺼도 돼요. 켜 두면 바탕화면 아이콘이 숨겨질 수 있어요.
  • 칸에는 꼭 필요한 것만 보여요. 제목이나 칸을 누르면 큰 창으로 자세히 나와요.
  • 혹시 모르니 가끔 ⚙ → 백업 · 초기화에서 파일로 내보내기를 해 두세요.
  • 더 자세한 방법은 대시보드 ⚙ → 사용 방법에 있어요.
